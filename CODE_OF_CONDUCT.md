# Code of Conduct

## Our Pledge

AI-Translator aims to be a welcoming and respectful open source project. We ask everyone who participates in this project to help keep discussions constructive, inclusive, and focused on improving the software.

## Expected Behavior

- Be respectful and considerate of different backgrounds, experience levels, and viewpoints.
- Use welcoming language and give constructive feedback.
- Keep discussions focused on the issue, pull request, or project topic.
- Assume good intent, and ask clarifying questions before drawing conclusions.
- Respect maintainers' time and project scope.

## Unacceptable Behavior

- Harassment, intimidation, threats, or personal attacks.
- Discriminatory language or behavior.
- Trolling, insults, dismissive comments, or repeated disruption.
- Publishing private information without explicit permission.
- Sharing secrets, API keys, tokens, or other credentials in public issues or pull requests.
- Any conduct that would reasonably be considered inappropriate in a professional open source community.

## Reporting Guidelines

If you experience or observe unacceptable behavior, please report it privately to the project maintainer. Include:

- A short description of what happened.
- Links to relevant issues, pull requests, comments, or screenshots.
- Any context that can help the maintainer understand the situation.

Reports will be reviewed as privately and fairly as possible. Maintainers may remove comments, close issues, reject contributions, or block participants when needed to protect the project community.

## Scope

This Code of Conduct applies to project spaces including GitHub issues, pull requests, discussions, documentation, and other community channels connected to AI-Translator.
