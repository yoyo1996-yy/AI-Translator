# V0.2 Release Notes

## Version Status

V0.2 is a local Windows/browser version of AI 随身同传. It is intended for local use on the Windows computer running the project.

Cloud deployment and mobile LAN access are not included in V0.2.

## Completed Features

- Local Next.js frontend on `http://127.0.0.1:3000/`.
- Local Realtime Proxy on `ws://127.0.0.1:3001`.
- Aliyun Bailian Realtime WebSocket connection through the local Proxy.
- Japanese to Chinese realtime listening mode.
- English to Chinese realtime listening mode.
- Chinese to Japanese push-to-talk translation.
- Chinese to English push-to-talk translation.
- Target language switch: `日本語` / `English`.
- Status panel for listening, recording, translating, playing, recovering, and error states.
- Playback controls:
  - mute
  - replay latest target-language audio
  - clear captions/history
  - recover listening mode
- Optional translation glossary support, disabled by default.

## Current Interaction Rules

### Other Speaker to Chinese

1. Select `日本語` or `English`.
2. Click `开始同传`.
3. The app listens to the other speaker.
4. Source subtitle and Chinese translation update in realtime.

### Chinese to Target Language

1. Hold `按住说中文`.
2. Speak one Chinese utterance.
3. Release the button.
4. The app commits the Chinese audio and generates target-language text/audio.
5. Playback finishes, then the app restores listening mode.

Chinese push-to-talk uses manual commit: button release submits the current Chinese utterance.

## Required Environment

Configure `<project-root>\.env.local`:

```text
DASHSCOPE_API_KEY=...
DASHSCOPE_WORKSPACE_ID=...
DASHSCOPE_REGION=cn-beijing
```

Do not print, copy, screenshot, or commit the real API key.

## Runtime Configuration

- Realtime model: `qwen3.5-livetranslate-flash-realtime`
- ASR model: `qwen3-asr-flash-realtime`
- Region: `cn-beijing`
- Frontend host: `127.0.0.1`
- Frontend port: `3000`
- Proxy host: `127.0.0.1`
- Proxy port: `3001`
- Chinese push-to-talk turn detection: `manual`
- Other-speaker listening turn detection: `server_vad`

## Known Limitations

- V0.2 is for local Windows/browser use only.
- Phone access is not supported yet because services bind to `127.0.0.1`.
- Chinese to Japanese/English is not true continuous realtime playback; audio is generated after button release.
- Browser audio playback may require user interaction.
- Translation quality may vary by sentence length, ambiguity, and background noise.
- Glossary support is available but disabled by default for realtime stability.
- No desktop app packaging yet.
- No cloud deployment yet.

## Recovery Guidance

Use `恢复听译` when:

- audio playback appears delayed
- current turn seems stuck
- the app stays in translating or playing state too long
- you want to discard the current Chinese turn

If recovery does not help:

1. Click `停止同传`.
2. Click `开始同传`.
3. Refresh the browser page if needed.
4. Restart `npm run dev:all` as the last local recovery step.
